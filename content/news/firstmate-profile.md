# First Mate profile (news scoring)

This file is the editable description of First Mate that the news scorer reads (PRD I-3). Edit it and the next run uses it, with no code change. Keep it factual: it is sent to the model verbatim.

## Who we are
First Mate (firstmate.tech) is a VC-funded software studio. Silicon Valley leadership, senior engineers based in the Philippines with real-time overlap with US hours. We ship for early-stage and growth-stage tech companies (startups, legal tech, fintech-adjacent, AI products) at breakneck pace, comfortable with ambiguous specs, trading speed against technical debt deliberately and never compromising on security.

## What we sell
- **MVP builds**: founders with no CTO; first real product in months.
- **Fractional CTO and engineering teams**: senior leadership plus a full team on demand.
- **AI and ML engineering**: product-minded engineers who build and verify real ML and LLM features, not just an API call.
- **Staff augmentation**: vetted senior engineers plugged into a client's existing team.

## How we work
- AI-native execution: engineers use Claude Code and Codex CLI daily. Context files (CLAUDE.md, AGENTS.md), plan-first work, subagents, worktrees, MCP, hooks, gated review pipelines and parallel agents are core skills. Changes in these tools directly change how we deliver.
- Ruthless build-vs-buy: prefer managed services and proven libraries; build custom only when the requirement is genuinely unique.
- Verification over vibes: we test and review everything an agent generates.

## Our stack
Next.js (App Router) and React, TypeScript, Node, Tailwind, Postgres and Supabase (auth, storage, RLS), Vercel, GitHub Actions, Python for ML work, and the Anthropic, OpenAI and Google model APIs.

## Who reads the digest
First Mate engineers, from juniors learning agentic workflows to senior engineers and fractional CTOs advising clients. They have under five minutes a day.

## What scores high (80-100)
- New frontier or coding-relevant model releases and material pricing, limit or capability changes (Claude, GPT/Codex, Gemini).
- Releases or breaking changes in Claude Code, Codex CLI, MCP, agent frameworks and other AI coding tools we or clients use.
- Breaking changes or major releases in Next.js, React, TypeScript, Supabase, Postgres and Vercel.
- Security advisories or incidents affecting our stack, dependencies, AI agents or supply chain.

## What scores medium (40-79)
- Practical engineering posts: agent workflows, evals, prompt and context engineering, testing AI-generated code.
- Notable open-source tooling, infra or database releases with plausible client impact.
- Business news that changes how clients buy or build (funding of AI-dev tooling, enterprise adoption, regulation touching software vendors).

## What scores low (0-39)
- General consumer AI news, celebrity or opinion pieces, hype without technical substance.
- Research with no near-term engineering impact, partnerships and marketing announcements.
- Topics unrelated to software delivery.

## Tags
- `new-model`: model or model-capability releases.
- `tooling`: developer tools, agents, CLIs, editors, MCP.
- `framework`: frameworks, libraries, languages, databases, platforms.
- `security`: vulnerabilities, advisories, incidents.
- `business`: pricing, funding, policy, market shifts.
