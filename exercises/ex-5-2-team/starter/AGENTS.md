# Release notes generator

Read `SPEC.md` first. It fixes every interface.

- Run `npm test` before you say you are done. Never edit files under `tests/`.
- Edit only the files you own in `OWNERSHIP.json`. If you need a change elsewhere, write it in your handoff note instead.
- Commit on your own branch. Do not merge, and do not rebase other people's branches.
- Finish with `handoffs/<your-name>.md`: a `## Done` section and a `## Test output` section with the real output.
