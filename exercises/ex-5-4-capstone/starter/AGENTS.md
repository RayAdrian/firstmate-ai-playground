# fm-capstone

A tiny todo library. Your job is to ship one feature through the full First Mate process (the feature is described in `FEATURE.md`).

## Commands
- `npm test`: the test suite. It must pass before any push.
- `bash scripts/gate-status.sh <pr#> <browser|review|uiux> <success|failure> <sha> "<desc>"`: a gate agent posts its verdict on the commit it reviewed.
- `npm run gate:merge -- <pr#>`: the only way to merge.
